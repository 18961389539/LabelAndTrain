# 项目化改造 · 真机验收清单（2026-10-10）

四批改动（L1 界面 / L2 数据模型 / L3 续点 / L4 资源隔离）**只在 offscreen 自动化下验证过**。
单元测试 1165 条 + 集成冒烟 13 步全绿，但下面这些事它们看不到：菜单实际排布、对话框的
手感、字体与间距、点击顺序是否顺手。

走一遍大约 10 分钟。**每一项都给了"不符时说明什么"**，所以看到异常不用猜。

---

## 0. 准备

用一个**测试数据集**（几张小图就够，别拿真项目试）。最好准备两个不同的文件夹，
下面第 5、6 项要用。

---

## 1. 项目菜单的位置与内容

打开程序 → `文件` 菜单。

**应该看到**：`文件` 菜单的**第一项**是 `项目 ▸`，展开后依次是

```
新建项目…
项目属性…
──────────
切换项目…            Ctrl+Shift+O
打开最近项目 ▸
──────────
打开项目设置文件夹
关闭项目
```

**不符时**：
- 项目菜单跑到菜单栏最左边成了顶级菜单 → 插入位置错了（应在 File 内部）
- 找不到「打开最近文件夹」→ 正常，它已并入「打开最近项目」

---

## 2. 新建项目向导

`项目 → 新建项目…` → 选一个**空文件夹** → 填名字（比如"螺丝划痕"）→ 选「实例分割」→ 保存。

**应该**：
1. 弹出文件夹选择框，起始位置是上次打开过的目录
2. 然后是属性对话框：显示所选文件夹的完整路径、项目名输入框、四个任务类型单选
3. 保存后**自动打开**该文件夹，标题栏显示 `… - [螺丝划痕] - …`
4. 该文件夹下出现 `.jllabel/project.json`（隐藏目录）

**不符时**：
- 对话框里"文件夹"那行没有路径 → 你会不知道自己在给哪个目录建项目
- 保存后没有自动打开 → `import_image_folder` 的调用链断了

---

## 3. 已是项目的文件夹

对**同一个文件夹**再走一次 `新建项目…`。

**应该**：弹出"已经是项目了，直接打开它吗？"→ 确认后直接打开，**清单不被覆盖**
（名字和任务类型还是刚才设的）。

**不符时**：如果它让你重新起名并覆盖 → `create()` 的拒绝覆盖逻辑失效了。

---

## 4. 标题栏

打开一个**没有**项目清单的普通图片文件夹。

**应该**：标题栏形如 `JLLabelingAndTrain v… - [文件夹名] - img_0.png [1/3]`
（项目名回退成目录名）。

**不符时**：标题里没有 `[…]` → `title_project_prefix` 没接上。

---

## 5. 关闭项目与续点（这条最重要）

1. 打开项目 A，翻到**第 3 张**图
2. `项目 → 关闭项目`
3. **应该**：回到空画布（文件列表空、标题栏不含项目名）
4. `项目 → 打开最近项目 → A`
5. **应该**：直接打开到**第 3 张**，不是第 1 张

**不符时**：
- 关闭后文件列表还在 → `close_project` 的清空没生效
- 重开回到第 1 张 → 续点没写或没读（看 `A/.jllabel/project.json` 里有没有 `last_file`）

---

## 6. 两个项目之间切换

打开项目 A（停在第 3 张）→ 打开项目 B（翻到第 2 张）→ `Ctrl+Shift+O` 切回 A。

**应该**：A 回到第 3 张，B 的进度不受影响。

再切到 B：**应该**回到 B 的第 2 张。

**不符时**：两边互相串 → 续点写到了同一个清单里（就是今天修的那个父目录 bug）。

---

## 7. 任务类型预选（训练窗口）

打开第 2 步建的那个「实例分割」项目 → `Train → Ultralytics`。

**应该**：Data 页的 **Task Type 里 Segment 已经是选中状态**，不用手点。

然后把 Task Type 改成 Detect，走完配置点 Start Training（或者只走到 Config 提交那步），
再关掉程序重开该项目 → **应该**预选变成 Detect。

**不符时**：
- 什么都没预选 → `_apply_project_task` 没接上
- 预选的是 Detect 而不是 Segment → 读到的不是这个项目的清单

---

## 8. 属性对话框

`项目 → 项目属性…` → 改名 → 保存。

**应该**：标题栏立刻变成新名字，**磁盘上的文件夹名字没有变**（项目身份是路径，名字只是标签）。

**不符时**：如果文件夹被改名了 → 严重，立刻停下告诉我。

---

## 9. 写失败要被看见（可选，需要只读目录）

把一个项目目录设为只读（或放网络盘），打开它、给标签面板加一个类别、切到别的文件夹。

**应该**：弹出一次警告，写明确路径 + "本次会话中这个项目的标签列表与标注输出目录不会被记住"。
同一个目录**再操作不会重复弹**。

---

我会去查对应那条链路。**第 8 项如果出现文件夹被改名，请单独标出来。**
